# UrbanNest Housing Price Predictor — Streamlit

A sleek Streamlit interface for the deep neural-network housing-price model
from the supplied UrbanNest Realty notebook.

## Important

The uploaded notebook does **not** contain a saved `.keras` model or fitted
preprocessor, and the original CSV dataset is referenced from Google Drive:

`cleaned_real_estate_final_price_v2.csv`

Therefore this package includes the complete application plus a training/export
script, but the trained model artifacts must be generated from your original
CSV before the predictor can make real predictions.

## 1. Project structure

```text
UrbanNest_Housing_Price_Streamlit/
├── app.py
├── train_model.py
├── requirements.txt
├── README.md
├── data/
│   └── cleaned_real_estate_final_price_v2.csv   <-- YOU ADD THIS
└── artifacts/
    ├── housing_price_model.keras                <-- generated by training
    └── preprocessor.joblib                      <-- generated by training
```

## 2. Install dependencies

```bash
pip install -r requirements.txt
```

## 3. Add the original dataset

Copy the same cleaned CSV used by the notebook into:

```text
data/cleaned_real_estate_final_price_v2.csv
```

## 4. Train/export the model

```bash
python train_model.py
```

This creates:

```text
artifacts/housing_price_model.keras
artifacts/preprocessor.joblib
```

The training script explicitly fixes the notebook issue where `input_dim` was
referenced before being defined:

```python
input_dim = X_train_processed.shape[1]
```

## 5. Launch the Streamlit app

```bash
streamlit run app.py
```

Then open the local URL shown by Streamlit.

## Model inputs

The notebook uses these features:

Categorical:
- status
- city
- state
- zip3

Numerical:
- bed
- bath
- acre_lot
- house_size
- has_prior_sale

Target:
- price

## Model architecture

The app uses the deep model architecture from the supplied notebook:

Input → Dense(128) → LeakyReLU → Dropout(20%)
→ Dense(64) → LeakyReLU → Dropout(20%)
→ Dense(32) → LeakyReLU
→ Dense(16) → LeakyReLU
→ Dense(1)

The notebook uses Adam with learning rate 0.1, MSE loss, RMSE metric,
early stopping with patience 10, and a batch size of 8192.

## Deployment

Once the two files inside `artifacts/` exist, the project can be deployed to
a Streamlit-compatible hosting environment. Keep the generated model and
preprocessor files in the `artifacts/` folder alongside `app.py`.
